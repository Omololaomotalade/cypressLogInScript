# Cypress Login Test (Positive Scenario)

This project contains an automated test written in [Cypress](https://www.cypress.io/) to verify the login functionality of a web application using valid credentials.

## 🚀 Features

* ✅ Positive login test using Cypress
* 📂 Organized test structure in `cypress/e2e`
* 🔄 Easy to extend for negative or edge-case scenarios

## 📄 Test Scenario

The test checks that a user with valid credentials can successfully log into the application.

### What’s covered:

* Navigating to the login page
* Entering valid username and password
* Asserting successful login via expected element or URL check

## 🛠 Technologies

* Cypress 12+
* JavaScript

## 📦 Installation

```bash
git clone https://github.com/Omololaomotalade/cypressLogInScript.git
cd cypressLogInScript
npm install
```

## ▶️ Running the Test

```bash
npx cypress open
```

Select the login test file from the Cypress UI and run it in your preferred browser.
